Advanced Tab Manager

Automatically organize tabs into groups based on URL patterns

Current Rules

Rules are checked from top to bottom and the first matching rule wins. Put more specific rules, like github.com/mozilla, above broader ones, like github.com.

    Settings

    When enabled, tabs that don't match any rule will be grouped together.

    Controls the order of managed groups in the Firefox tab bar and the rule list in the popup.

    Switching to Random recolors open groups named after a rule (and "etc"); other groups are left alone. New groups get a color not yet used in their window when one is left, and keep it. Groups that end up next to one of their own color are recolored when tabs are sorted.

    The selected tab takes a tone of its group's color, outlined in its container's color. This replaces your Firefox theme while a grouped tab is selected.

    Backup & Restore

    Export your rules and settings to a JSON file or restore them from a previous backup.

    Merge keeps existing rules. An imported rule with the same group name updates the existing rule while preserving its creation position.

    Automatic backup

    • Backups travel through Firefox Sync. Sign in to Firefox Sync and tick "Add-ons" in its settings. Firefox syncs about every 10 minutes.
    • Firefox for Android does not sync them.
    • Removing the extension deletes these backups from every synced device. Use Export Rules for a copy that survives.
    • What is sent: rule names, URL patterns, colors, the four settings above, and a device label with your operating system name. Firefox Sync encrypts it.
    • Turning this off stops updates. The last copy stays in Firefox Sync until you delete it from the list.
    • Restore uses the mode chosen under "Backup & Restore".
