# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub:
[Report a vulnerability](https://github.com/lemiorhan/firefox-advanced-tab-manager/security/advisories/new).

Include a description of the issue, the steps to reproduce it, and the impact
you expect. You will get an acknowledgement, and a fix will be coordinated
with you before any public disclosure.
